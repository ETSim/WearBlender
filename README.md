# Wear Blender

A collection of Blender scenes for learning and teaching wear effects in shaders, geometry nodes, and dynamic painting.

These example files demonstrate various techniques for simulating wear in 3D models — including edge wear, scratches, rotating normal maps, and object proximity effects.

## Scenes

- **Edge Wear in Shaders**:
Based on popular tutorials, shows how to simulate worn edges using curvature and masks.

- **Scratches on Surfaces**:
Realistic micro-scratches using procedural textures and shader tricks.

- **Rotating Normal Maps**:
Demonstrates how to animate or rotate normal maps in shaders for dynamic surface details.

- **Dynamic Paint**:
Interactive wear and marks using Blender’s dynamic paint system.

- **Geometry Nodes – Proximity Wear**:
Use object proximity to drive shader or geometry-based wear effects.

How to Use
Open any .blend file in Blender (Tested in 4.5 lts).

1. Explore the shader editor or geometry nodes editor.
2. Toggle visibility or play animation to observe the effects.
3. Use as a learning tool or a base for your own projects.
